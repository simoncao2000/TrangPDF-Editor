## Regenerate

Run `python3 test-corpus/generate.py` with pypdf 5.4.0, cryptography (AES support), ReportLab 4.1.0 and Pillow
12.1.1. Use the repository's UI font assets and installed Fontsource packages. The generator skips the Arabic
fixture if its local font is missing. The founder-supplied performance fixture is maintained separately.

Use `python3 test-corpus/generate.py --only pages-50.pdf` to replace one fixture.
For the size-limit message, `python3 test-corpus/generate.py --huge` writes a sparse
`huge-over-500mb.pdf` in the OS temporary directory and prints its path.
